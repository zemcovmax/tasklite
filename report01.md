Отчёт по практической работе №2

Тема: Первая пользовательская функция и ветвление.

Название проекта: TaskLite — мини-задачник.

Ссылка на репозиторий: https://github.com/zemcovmax/tasklite

Рабочая ветка: feature/first-feature

1. Реализованная функция

В проект TaskLite добавлена функция удаления задач.

Пользователь может нажать кнопку «Удалить» рядом с задачей. После нажатия задача исчезает из списка и удаляется из localStorage.

2. Сценарий до и после

До изменений пользователь мог добавлять задачи и отмечать их выполненными.

После изменений появилась возможность удалять ненужные задачи. Удалённые задачи не появляются после обновления страницы.

3. Изменённые файлы
js/ui.js — добавлена функция deleteTask(id) и кнопка удаления.
css/styles.css — добавлено оформление кнопки удаления.
4. Проверка работы

Проведены ручные проверки:

Добавление и удаление задачи.
Сохранение задачи после обновления страницы.
Удаление выполненной задачи.

Функция проверена в браузере.

5. Работа с Git
Создана ветка feature/first-feature.
Изменения проверены командами git diff и git status.
Создан коммит 93794ff — feat: add task deletion.
Выполнено слияние командой git merge feature/first-feature.
Изменения отправлены на GitHub командой git push.

Способ слияния: Fast-forward.

6. Обнаруженная проблема

При работе с Git возникла проблема с повторной инициализацией репозитория. Также первоначально не была настроена идентификация пользователя Git. Проблемы были устранены, после чего работа с ветками и отправка изменений прошли успешно.

7. Итог

В проект TaskLite добавлена новая пользовательская функция. Работа выполнена в отдельной ветке, изменения проверены и объединены с основной веткой main.
