# TaskLite

Простой минималистичный список задач (To-Do list) на чистом HTML, CSS и JavaScript.

Данные сохраняются локально в браузере с помощью `localStorage` и не требуют сервера.

## Функции
- Добавление задач через форму.
- Отметка выполнения (чекбокс).
- Сохранение данных после перезагрузки страницы.

## Стек
HTML, CSS, JavaScript (ES6).
